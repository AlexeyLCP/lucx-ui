description: 'Manage external tunnel-server sidecars that run next to the Xray
  core. Cores: (1) NaiveProxy — Caddy with forward_proxy (klzgrad, HTTP/2
  padding), optional routeThroughXray SOCKS bridge; (2) olcRTC — TCP-over-WebRTC
  via meet rooms (Jitsi/Telemost/WB Stream), YAML config, olcrtc:// connect URI;
  (3) qWDTT — WireGuard over VK TURN (SpaceNeuroX wdtt-server), CLI flags,
  qwdtt:// URI + subscription JSON. Each core is supervised (start/stop/restart,
  ring logs, binary upload/download); the reconcile job (every 10s) revives a
  crashed core. All endpoints live under /panel/api/tunnel and require a
  logged-in session or Bearer token. LucX-UI only.'
