title: Scanner Guard
description: Blocks incoming connections from known RKN/government scanner
  subnets. CIDR lists are fetched from operator-configured HTTPS sources and
  installed as ipset hash:net sets (lucx-sg4 / lucx-sg6) with owner-marked
  iptables/ip6tables INPUT rules (comment lucx-scanguard, conntrack NEW only);
  on hosts without the ipset/iptables tooling the guard uses native nftables
  instead — one owned table (lucx_scanguard) with sets lucx-sg4/lucx-sg6 and a
  hooked input chain, replaced atomically per refresh. The reconcile job (every
  30m) re-ensures rules after reboot/iptables flush and re-fetches lists at most
  once per 6h; a broken source aborts the refresh and keeps the previous
  blocklist. Whitelisted subnets are excluded before install. Linux only. All
  endpoints live under /panel/api/scanguard and require a logged-in session or
  Bearer token. LucX-UI only.
